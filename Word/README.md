## 准备

1.  下载公文字体（参考文末链接）。
2.  安装字体后，**重启 Word**。
3.  在【开始】选项卡点击“创建样式”。
4.  输入名称，点击【修改】进入格式设置界面。

## 属性说明

-   **样式类型**：选择“链接段落和字符”。这个作用是既可以修改一整段文字也可以修改几个选中的文字。
-   **样式基准**：当前这个样式需要参考哪个样式，一般选择“无样式”。
-   **后续段落样式**：比如我标题回车后的样式，另起一行应该是正文，所以可以根据这个来判断后续样式。

## 页面设置

进入【布局】→【页边距】→【自定义页边距】，设置如下：

-   上：3.7 cm
-   下：3.5 cm
-   左：2.8 cm
-   右：2.6 cm

## 模板导出和替换
文件-另存为
保存类型为 “启用宏的 Word 文档(*.dotm)”


将配置好的 `Normal.dotm` 文件替换至以下路径：

```bash
%appdata%\microsoft\templates
```

可通过 `Win + R` 直接打开该目录进行替换。替换后重启 Word。

如果替换不了，试着先打开一个 word 文档，它会自动创建一个模板，再打开开发者工具
> 文件-选项-自定义功能区，主选项卡-选中复选框
找到文档模板，选用备份的文件。
再或者对于单个word文档：
接着在管理器中，右侧关闭文件，选择备份文件，将右侧的样式覆盖左侧。
